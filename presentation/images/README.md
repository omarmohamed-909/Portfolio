## Tips for great screenshots
- Use **Full Screen (F11)** — hide browser chrome
- Make sure **Dark Theme** is active
- Fill the dashboard with **real data** before shooting
- Minimum width: **1280px**
- For the messages inbox, make sure you have 3–5 real messages showing
