Security Architecture

Three roles. Every endpoint guarded.

Admin · Viewer · Public — enforced by RBAC middleware server-side. The Viewer account exists purely for safe live demos.

🍪
HttpOnly Cookies
JWT never touches localStorage — immune to XSS token theft.
🛡️
DOMPurify + Helmet
User HTML sanitized before DOM injection. CSP headers enforced.
🔒
Strict CORS
API accepts requests from one configured origin only — no wildcards.
🚫
RBAC Guard
Viewer accounts receive 403 on any mutation — server-side, no exceptions.
